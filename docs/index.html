Know what the log means.

Start with your first ECU log and work up to detailed comparisons. No tuning degree required. Every explanation should lead back to actual measurements, not guesses.

01 / Your first log in 3 steps

  1. Record and export a datalog in the software for your ECU. You need a real recorded session, not just a tune file.
  2. Open RAWEST SIGNAL, choose Analyze my log, and select the exported file on your device. You can also drag it into the drop zone on desktop.
  3. Review the findings. See the plain-English overview, then the 4.0 event timeline. Tap an event to inspect surrounding RPM, throttle and mixture measurements.
A missing channel is not a passing check. Even when the app reports no alerts, it cannot certify that your car or tune is safe.

03 / Should the graph use AFR or Lambda?

Lambda is the default. It expresses fuel mixture relative to the stoichiometric point for the fuel actually being used. A real comparison needs both Measured lambda and Target lambda from separate source columns.

AFR is an optional view when actual and target AFR were both logged, or when actual/target lambda can both be converted using the ECU's logged stoichiometric AFR. The app must not assume gasoline stoichiometry for an E85 or flex-fuel run.

ReadingInterpretation
Lambda 1.00Stoichiometric for the current fuel; not a safe WOT target by itself.
Actual lambda above targetMeasured mixture is leaner than the commanded target, assuming valid channels and matching conditions.
Actual lambda below targetMeasured mixture is richer than the commanded target.
Do not use a single graph reading to decide fuel or ignition adjustments. Sensor calibration, load, closed-loop behavior, fuel cut and transient enrichment all matter.

04 / When a channel looks wrong

  1. Open the Sensors tab after importing a log.
  2. Look for source names that uniquely match RPM, TPS, measured lambda, target lambda, fuel pressure and other sensors.
  3. Confirm suggested mappings manually. If none exists, open full sensor settings.
  4. Verify units and calibration in the ECU software, especially analog pressure sensors.
  5. Re-run your analysis after correcting the channel selection.

If Target AFR isn't present, try logging Target lambda and (if an AFR presentation is needed) stoichiometric AFR. The graph explains when it cannot show a matched target.

05 / Add manuals and reference documents

There are two different uploads: ECU datalogs to analyze and written documents to consult. They are not interchangeable.

Import a reference on your device

  1. Open RAWEST SIGNAL and import a real log.
  2. Go to 02 · SIGNAL Guide and expand My reference documents.
  3. Choose a .txt, .md, .markdown, .csv or .json file containing reference text.
  4. Ask a question. Matching sections are shown separately as Reference document excerpts. They are not proof of a real engine condition.

Reference text is saved in the local browser, not your GitHub account or an online AI service. Current limits: up to 10 files, 200 KB per file, 500 KB total. Remove old documents from the same panel.

What about PDFs?

PDF text extraction is not currently built into SIGNAL. Export or copy the readable content from a PDF to .txt or .md and import that text. Scanned-image PDFs require OCR first; uploading a raw PDF to the log input does not teach the app its contents.

Publish guides on the public website

On the GitHub repository, choose Add file → Create new file or Upload files, put public guides under docs/, and commit changes. Only publish materials you have permission to share. Public repo documents are visible to everyone. This is separate from importing private references locally.

A searchable text library is not model training or an AI knowledge base. It shows document excerpts alongside deterministic, log-based explanations.

06 / My Garage and reports

Use My Garage to record each project car's basic information, modifications, fuel system and tuning notes. Save a backup before changing browsers or devices. Garage data currently lives on the same browser.

Use Compare to save a baseline log and inspect matched RPM/MAP conditions after another session. Comparison is blocked or qualified when too little overlapping evidence exists.

Use Report → Print / save PDF to open the browser's print dialog and choose Save as PDF. You can also download a standalone HTML report to share without uploading the original log.

07 / Privacy, data and safety

RAWEST SIGNAL is a client-side web app. ECU logs and imported text references are processed on your device. There is no account system, remote file storage, human tuner review, automatic ECU flashing, or online AI assistant in this release.

Your saved references, configuration, baseline and Garage may be lost if your browser data is erased. Use backup/export features for data you want to keep.

Do not publish private datalogs, addresses, VINs, tune files, credentials, or copyrighted workshop manuals into the public GitHub repo.

08 / Troubleshooting

Target AFR button has no line

On many MaxxECU logs there is no literal target AFR channel. Show actual/target lambda first. If AFR cannot be computed from suitable logged sources, the app will tell you rather than draw fabricated values.

The graph is empty

Confirm your file contains recorded RPM/runtime and valid channels. Check Sensors for mapping collisions. Some WOT analyses also need TPS and reliable lambda source columns.

The page looks like an older version

Reload the page while online. If installed as an app, close/reopen it; the service worker may be serving an older cached copy. Clearing site storage also clears saved browser data, so back up first.

It says "not enough data"

That's a data-quality limit, not a broken rating. Capture the sensor channels needed for the question and verify their calibration before interpreting the result.

09 / Turn SIGNAL into a branded website

It's already live on GitHub Pages at whiiskerz.github.io/pullsheet. GitHub Pages serves your HTML, CSS and JavaScript without needing a paid server.

For your own domain, buy or use a name you control, then navigate to your repo Settings → Pages → Custom domain. Add the DNS record recommended by GitHub for your selected subdomain or apex domain and enable HTTPS after it becomes available.

Example: a domain like signal.yourbrand.com would normally use a CNAME pointing to whiiskerz.github.io. The name is only an example, not a registered or configured domain.

To add online accounts, cloud uploads, subscription billing or genuine AI document indexing, you'll eventually need additional services, security controls and explicit data-consent handling. A domain alone doesn't add those capabilities.
