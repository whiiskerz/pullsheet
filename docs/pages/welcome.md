# Start here

RAWEST SIGNAL turns exported ECU data into readable evidence. You can explore a log without knowing every sensor abbreviation.

## Your first session

1. Record and export a datalog in your ECU software.
2. Open [RAWEST SIGNAL](../) and tap **Analyze my log**.
3. Choose your exported file. Wait until the analysis finishes.
4. The page **automatically scrolls to the findings** once a new log imports successfully.
5. Read the plain-English overview, then select a point in **Moments** to see the surrounding readings.
6. Open **Sensors** if a field says unknown or has an unexpected value.

> No alerts does not mean the engine is safe. SIGNAL can only review the measurements present in your actual log.

## Where things live

| Area | Use it for |
| --- | --- |
| My log | Import and inspect a real recorded session |
| Moments | Find and review flagged time/row ranges |
| SIGNAL Guide | Ask plain-language questions about observed events |
| Sensors | Confirm channel names and units |
| Compare | Check differences between comparable runs |
| My Garage | Save vehicle information and changes |
| Tune Studio | Inspect genuine MaxxECU calibration files |

## Don't know where to start?

See [Supported files](#/file-formats) first. For the meaning of fuel readings, read [Lambda vs AFR](#/lambda-afr).
