# Share and export results

RAWEST SIGNAL generates branded summaries from your imported log. Useful when discussing a question with a tuner, shop or a friend.

## Save a PDF

1. Import your datalog.
2. Open **06 · Report** inside the guided review.
3. Select **Print / save as PDF**.
4. Choose **Save as PDF** in your browser's print dialog.

You can also **download a standalone HTML report** to keep a copy that opens in a browser.

## What a report includes

The review may include selected logged events, coverage status, limits and next checks. It does not include certified diagnoses or guaranteed power claims.

## Protect personal data

Check a report before sharing it. A public GitHub repository or social post is not a safe location for confidential logs or personal vehicle details.

See [Warnings and confidence](#/safety-alerts).
