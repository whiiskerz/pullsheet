# Privacy and limitations

The public RAWEST SIGNAL website runs analysis on your device in the browser. Imported ECU logs are parsed locally; the release does not include user accounts, remote log storage, an online AI chatbot or automatic ECU flashing.

## Stored locally

- My Garage profiles and browser settings.
- Selected sensor mappings and comparison baseline.
- Imported text reference excerpts (within local storage limits).

Clearing site data or changing browsers can remove local information. Export backups and reports first.

## Safety boundaries

- A log cannot verify physical sensor calibration by itself.
- Absent channels are never proof that a system is healthy.
- Event priority is not a standalone mechanical diagnosis.
- The comparison report cannot establish that a tune change caused a difference.
- Reports are not certificates of roadworthiness, performance or safety.

## Public GitHub content

Do not commit customer information, private logs, addresses, credentials, VINs, or copyrighted workshop manuals to the public repository. Publishing a Markdown page makes it publicly accessible.
