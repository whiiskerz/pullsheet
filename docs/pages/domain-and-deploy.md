# Publish with your own domain

RAWEST SIGNAL already works as a public website on GitHub Pages. You can give it a memorable address without moving the app to another hosting service.

## GitHub Pages

The current deployment is [RAWEST SIGNAL](https://whiiskerz.github.io/pullsheet/). The main app is at the root and the docs are at [/docs/](./).

## Connect your domain

1. Buy or use a domain you control.
2. In the repository go to **Settings → Pages → Custom domain**.
3. Enter the hostname you want to use and save it.
4. Configure the matching DNS records at your domain provider using GitHub's instructions.
5. Enable HTTPS after GitHub offers the certificate.

For a subdomain, a CNAME commonly points to the GitHub Pages host **whiiskerz.github.io**. The exact address and configuration depend on the actual domain you own.

For step-by-step current instructions see [GitHub Pages domain documentation](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site).

## What a domain does not do

A domain alone does not add accounts, cloud backups, payment handling, AI document ingestion or secure private file storage. Those require separately designed services.
