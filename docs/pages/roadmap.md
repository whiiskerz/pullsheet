# The RAWEST SIGNAL roadmap

This page distinguishes **what exists today** from things we'd need to build before calling the product a full cloud platform.

## Shipped in the local-first 4.x app

- Guided datalog import and plain-language analysis.
- Interactive log events and fuel mixture plots with source limitations.
- Browser-local sensor mapping and document reference search.
- Matched-condition log comparison and My Garage.
- Exportable reports and a searchable public documentation hub.
- Automatic scrolling to findings after a successful new import.

## Highest-value next investments

1. **Hands-on test on real MaxxECU exports**, desktop and mobile. Expand regression fixtures for rare log formats.
2. **More complete reference ingestion**: PDF text extraction, page citations and optional OCR with explicit file-size and privacy limits.
3. **A true cloud identity layer**: opt-in accounts, sync, private backups and deletion controls.
4. **Reliable online document intelligence**: a real retrieval layer that cites documents without treating them as logged evidence.
5. **Error monitoring and feedback**: voluntary crash reports, support form, changelog and release transparency.
6. **Branding and marketing**: custom domain, public landing page, terms/privacy pages and clearly defined paid features.

## Product principle

Start simple, reveal expert controls when needed, and never pretend unknown engine measurements are verified.
